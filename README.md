# MONO Finance

Нативное iOS-приложение для личных финансов на Swift и SwiftUI (iOS 18+). Работает полностью на устройстве: счета, операции, переводы, голосовой ввод, аналитика, бюджеты, цели, импорт выписок.

## Установка на iPhone без Mac (Windows + Sideloadly)

Приложение собирается на облачном Mac в GitHub Actions при каждом изменении кода. Результат — неподписанный файл `MonoFinance.ipa`. Sideloadly подписывает его вашим Apple ID и ставит на iPhone.

**Один раз подготовить:**

1. Установите на Windows **iTunes и iCloud с сайта Apple** (apple.com). Версии из Microsoft Store с Sideloadly не работают.
2. Установите **Sideloadly** с сайта sideloadly.io.
3. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить, перезагрузить телефон и подтвердить включение.

**Установка:**

1. Скачайте `MonoFinance.ipa`: репозиторий на GitHub → **Releases → «MONO — последняя сборка»** (или **Actions → последняя успешная сборка → Artifacts**).
2. Подключите iPhone кабелем к компьютеру, разблокируйте и нажмите «Доверять этому компьютеру».
3. Откройте Sideloadly, перетащите туда `MonoFinance.ipa`, введите свой Apple ID и нажмите **Start**. Пароль Apple ID передаётся только Apple для подписи.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
5. Откройте MONO.

**Каждые 7 дней** (ограничение бесплатного Apple ID): подключите iPhone и повторите шаг 3 с тем же файлом или новой сборкой. Приложение **не удаляйте** — данные сохранятся. Если приложение перестало открываться, значит, истёк срок подписи: переустановите его поверх через Sideloadly.

С платным аккаунтом Apple Developer ($99 в год) срок подписи — год, а сборки можно получать через TestFlight без компьютера.

## Сборка на Mac (Xcode)

1. Установите Xcode 16 или новее.
2. Откройте `MonoFinance.xcodeproj`.
3. Выберите цель **MonoFinance** → **Signing & Capabilities** → **Team**: ваш Apple ID (Personal Team).
4. Если Xcode сообщит, что идентификатор `uz.mono.finance` занят, замените его на свой, например `uz.<имя>.monofinance`.
5. Подключите iPhone и нажмите **Run**.

Проект генерируется из `project.yml` утилитой XcodeGen: `xcodegen generate`.

## Что умеет

- **Счета:** Kapitalbank, Uzum Bank, Orient Finans Bank, Trastbank, наличные и другие. Реальный начальный остаток, карты, вклады, кредитные карты, валюты, архив.
- **Операции:** расходы, доходы, переводы между своими счетами (в том числе между валютами), комиссии отдельной операцией, возвраты, корректировки баланса. Поиск, фильтры, история изменений, отмена удаления, фото чеков.
- **Голосовой ввод:** Apple Speech на устройстве, живая расшифровка, несколько операций в одной фразе, черновики с быстрыми исправлениями. Сохраняется только после подтверждения. Если язык не поддерживается системой, фразу можно ввести текстом — разбор тот же.
- **Аналитика:** расходы по категориям (кольцо с выбором сектора), доходы и расходы по дням, неделям и месяцам, сравнение с прошлым периодом, магазины, движение по счетам, обязательные траты, необычные траты, найденные подписки, прогноз накоплений.
- **Планы:** лимит на месяц и бюджеты категорий с переносом остатка, цели (по взносам или по балансу счёта), запланированные траты, регулярные платежи с напоминаниями.
- **Категории:** свои категории и значки, умная категоризация (Korzinka → Продукты, Yandex Go → Такси), обучение на ваших исправлениях.
- **Ассистент:** вопросы о деньгах, ответы по реальным данным, без интернета. По желанию — пояснения внешней модели через ваш собственный сервер.
- **Импорт выписок CSV/XLSX:** автоопределение колонок, проверка дублей, предпросмотр, запоминание сопоставления.
- **Курсы валют:** официальные курсы ЦБ РУз и ручные.
- **Защита:** Face ID / код-пароль, скрытие сумм, шторка в переключателе приложений, зашифрованные резервные копии (AES-256-GCM), экспорт CSV, проверка целостности.
- **Прочее:** онбординг, демо-режим в отдельной базе, быстрые действия на иконке, команды Siri и «Быстрых команд», тёмная и светлая темы, Dynamic Type, «Уменьшение движения».

## Честно о проверке

- **Ядро MonoKit** (деньги, учёт, база данных, аналитика, голосовой парсер, ассистент, импорт) покрыто 121 тестом. Тесты проходят на Linux (Swift 6) и на macOS в GitHub Actions.
- **Экраны** собираются в облачной сборке под iOS. На реальном iPhone и в симуляторе интерфейс автором не запускался: визуальные мелочи и поведение анимаций нужно проверить на устройстве.
- **Банки:** официального доступа к данным банков для личного использования нет, поэтому автоматической синхронизации нет. Приложение честно это показывает и предлагает импорт выписки. Шаблоны выписок конкретных банков не заявлены как проверенные: колонки определяются автоматически и подтверждаются вами.
- **Узбекская речь:** поддержка проверяется на устройстве при запуске. Если системный распознаватель узбекский не поддерживает, работает ввод фразы текстом.

## Архитектура

```
MonoFinance/               приложение (SwiftUI, Swift 5 mode, iOS 18)
  App/                     точка входа, навигация, App Intents
  Core/                    FinanceStore, настройки, сервисы (курсы ЦБ, экспорт, чеки, уведомления)
  DesignSystem/            токены, цвета, типографика, анимации, компоненты
  Features/                Overview, Accounts, Transactions, VoiceInput, Analytics, Budgets,
                           Categories, Import, AI, Settings, Onboarding
  Security/                блокировка, Keychain, зашифрованные копии
Packages/MonoKit/          ядро без UI (Swift 6), тестируется отдельно
  MonoCore                 Money (Int64 в минимальных единицах), счета, операции, правила учёта, курсы, периоды
  MonoStorage              SQLite: транзакции, ограничения, миграции, журнал изменений, снимки
  MonoAnalytics            итоги, ряды, бюджеты, цели, прогнозы, поиск закономерностей
  MonoIntelligence         категоризация, голосовой парсер, ассистент, инсайты
  MonoImport               CSV (UTF-8/UTF-16/CP1251), XLSX (собственный ZIP/Deflate), сопоставление, дубли
  MonoBankSync             интерфейс банковских адаптеров без имитации подключения
Design/tokens.json         единый источник дизайн-токенов (генерирует Swift и CSS)
```

Тесты ядра: `cd Packages/MonoKit && swift test`.

## Данные и приватность

Все данные хранятся только на iPhone в SQLite с защитой файлов iOS. Аккаунтов и облака нет. Из сети загружаются только курсы ЦБ РУз (без ваших данных). Голос распознаётся на устройстве; серверы Apple — только с вашего согласия. Пароли от банков приложение не запрашивает и не хранит.
